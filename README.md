This repository hosts Xila's public organization profile, default issue and pull request templates, and the shared README writing template.

## Shared templates

- [README starting point](templates/README.md) and [adaptation guide](templates/README-guide.md): a common presentation frame with optional body sections for different repository roles.
- [Issue templates](.github/ISSUE_TEMPLATE/): bug reports, feature requests and engineering tasks.
- [Pull request template](.github/pull_request_template.md).

## Organization profile

The public organization introduction lives in [profile/ReadMe.md](profile/ReadMe.md). Its artwork is generated in [brand](https://github.com/xila-project/brand) and kept here as deployment copies.

## Contributing

Propose community-documentation and template changes in this repository. Keep project implementation and technical instructions in their owning repositories, and use the [Xila Matrix room](https://matrix.to/#/#xila:anneraud.fr) for discussion.
