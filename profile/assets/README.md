# Xila identity deployment copies

Source: `xila-project/brand` at commit `a7f0b4441c2328935d92970a585cdfe999f0537e`, identity version `1.1.0`.

The lockups use the selected Continuity symbol and Montserrat Bold (700) outlined as SVG paths. Black/ink is for light backgrounds; white is for dark backgrounds. No installed font or access to the private brand repository is required to display them.

The glyphs originate in Montserrat, whose source-font license is SIL OFL 1.1. These rendered wordmarks are distributed with Xila artwork under the repository's existing license. Update the vector copies from brand and record the actual imported commit. GitHub controls README body typography; the outlined logo preserves the brand font independently.
